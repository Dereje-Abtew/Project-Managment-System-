## 🔧 Need to Customize?

### **Change Colors**
Edit: `frontend/src/constants/companyConstants.js`

```javascript
export const COMPANY_BLUE_COLOR = '#064e3b';      // Your color
export const COMPANY_YELLOW_COLOR = '#F1B31C';    // Your accent
```

### **Adjust Spacing**
Edit: `frontend/src/index.css`

Search for `padding` or `margin` and adjust values.

### **Modify Border Radius**
Edit: `frontend/src/index.css`

Search for `border-radius` and adjust values.
